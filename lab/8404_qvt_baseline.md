## 왜 16:52 수정이 필요했나

QVT-ARE는 López de Prado Triple Barrier로 **TP +2.5×ATR / SL −1.2×ATR = 손익비 2.08:1** 을 설계한다.
라이브 신호 7종 실측: TP +7.9~17.7%(중앙값 **+14.3%**) / SL −3.8~8.5%(중앙값 **−6.9%**).

그런데 `8404/core/trailing_stop_manager.py:257`의 **TP 돌파 락인**이 이를 잘라낸다.

```python
if raw_move >= tp_pct:                      # tp_pct = TAKE_PROFIT_PCT
    new_sl_price = entry * (1 + tp_pct)     # 바닥
    new_tp_price = entry * (1 + tp_pct * 3) # 천장
```

`TAKE_PROFIT_PCT`가 1.2%였으므로 이익은 **+1.2~+3.6% 상자**에 갇히고 손실만 −6.9%까지 열려 있었다.
**실질 손익비 0.52:1 — 설계의 1/4.**

⚠️ 이 락인은 `USE_TRAILING_STOP`과 **무관하게 항상 실행**된다(코드 주석: "트레일링 플래그와 독립 실행").
8404는 트레일링이 꺼져 있어 안전하다고 볼 수 없었다.

| 설계 TP / SL (중앙값) | +14.3% / −6.9% |

## 무엇을 보고 판정하는가

1. **이익거래가 +3.6%를 넘는가** ← 종전 천장. 넘으면 절단이 풀린 것이다.
2. **실현 손익비가 2.08:1에 근접하는가** (종전 0.52:1)
3. **건당 순손익(bp)이 양수인가** — 수수료 왕복 10bp를 넘어야 한다
4. **t값** — |t|<2면 우연과 구별되지 않는다
