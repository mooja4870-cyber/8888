# 프로젝트 맞춤 작업 규칙

## 봇 앱 실행 규칙
- 사용자가 "8개 봇 앱 실행해줘" 또는 봇 실행을 요청할 때에는, 대시보드 UI인 `app.py`뿐만 아니라 실매매 전담 엔진인 `bot.py`까지 8개 봇(8401, 8402, 8403, 8404, 8405, 8407, 8408, 8409) 모두 쌍으로(`app.py` + `bot.py`) 백그라운드에서 동시 기동한다.

## 코드 수정 및 파일 수락 규칙
- 코드 생성 및 수정 작업 시 사용자가 수동으로 'Accept all' 버튼을 클릭하지 않아도 작업 내용이 자동으로 디바이스 디스크 파일에 즉시 수락 및 반영(Auto-Accept)되도록 수행한다.
